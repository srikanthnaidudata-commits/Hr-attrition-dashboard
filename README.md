# HR Attrition Analysis Dashboard

## Project Overview

This project focuses on analyzing employee attrition trends using the IBM HR Analytics dataset. The dashboard was developed in Power BI to identify factors contributing to employee turnover and provide actionable workforce insights.

## Business Problem

Employee attrition can significantly impact organizational productivity and costs. The goal of this project is to analyze workforce data and identify patterns that influence employee retention and turnover.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Dashboard Features

* Employee Attrition Analysis
* Department-wise Attrition Tracking
* Workforce Demographics Analysis
* Job Role Analysis
* Interactive KPI Dashboard
* Dynamic Filtering and Reporting

## Key Performance Indicators (KPIs)

* Total Employees
* Attrition Count
* Attrition Rate
* Average Age
* Department-wise Attrition
* Job Role Distribution

## Key Insights

* Identified departments with higher attrition rates.
* Analyzed employee turnover across job roles.
* Evaluated workforce demographics.
* Highlighted trends impacting employee retention.
* Provided data-driven HR insights.
